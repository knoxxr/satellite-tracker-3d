Google Maps 3D API 키 설정

Google Cloud Console에서 발급받은 API 키를 입력하면 실제 3D 건물과 지형이 포함된 Google Photorealistic 3D Tiles 및 Google Maps 3D(<gmp-map-3d>) 엔진을 즉시 활성화할 수 있습니다.

권장 Google Cloud API 활성화 항목
  • Map Tiles API — CesiumJS 위에서 Google Photorealistic 3D Tiles 렌더링
  • Maps JavaScript API — Google Maps 3D 네이티브 엔진(<gmp-map-3d>) 사용

키는 현재 브라우저(localStorage)에만 저장되며 외부 서버로 전송되지 않습니다.
